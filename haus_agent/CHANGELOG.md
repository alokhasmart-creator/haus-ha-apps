# Changelog

## 0.1.2
- Fixes a crash when HAUS Cloud can't be reached for a while (for example during a network outage); the app now keeps retrying instead of restarting.

## 0.1.1
- Clear names and help text for the settings on the Configuration tab.
- Refuses commands to devices that are unavailable in Home Assistant, with a clear message in the app.
- LG TV remote keys and IR remote activities work remotely.

## 0.1.0
- First release: connects Home Assistant to the HAUS app through HAUS Cloud, with no port forwarding.
